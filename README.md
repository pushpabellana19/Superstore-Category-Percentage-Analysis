# Superstore Category-wise Percentage Analysis

## Task Overview
This Task focuses on analysing Superstore sales data using Google Sheets. The main objective is to calculate the percentage contribution of each product category to total sales.

## Dataset
Superstore Sales Dataset

## Work Completed
- Calculated total sales for Furniture, Office Supplies, and Technology.
- Calculated the percentage contribution of each category.
- Calculated overall total sales.
- Created a percentage contribution table.
- Created a pie chart to visualize category-wise sales contributions.

## Tools Used
- Google Sheets
- SUMIF Function
- SUM Function
- Percentage Calculation
- Pie Chart

## Key Findings
- Furniture contributed approximately 32.30% of total sales.
- Office Supplies contributed approximately 31.30%.
- Technology contributed approximately 36.40%.

Technology had the highest contribution to total sales.

## Conclusion
This analysis helped understand the sales contribution of each product category and compare their performance using percentages and a pie chart.
